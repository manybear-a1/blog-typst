## 判断した点
- **原文の誤記・文字化けの扱い**: HTML の `re.VERBOSE` 節に「入り組んだ正規表現ははバックスラッシュ」という重複した「は」がある。下書きは「入り組んだ正規表現はバックスラッシュ」と文脈に合った正しい形に整えており（プロンプト「原文の扱い」の許容行為）、修正版でも維持した。同節末尾の ASCII ピリオド「高速です.」や use-string-methods 節の「必要とされていなでしょう」の脱字は、下書きでは該当部分を削除・言い換えているため問題にならず、追加修正はしなかった。
- **まとめカードを作らなかった箇所**: prefixmatch() と search() は並列項目が2つであり、プロンプトのまとめカード規則（3つ以上が対象）に該当しないため作らなかった。また、非貪欲数量子は4項目が同一の挙動を共有するため、一覧の逆方向カードは「記号群 → できるだけ少ないテキストにマッチ」という共通挙動を問う形にした（個別の意味のペアは原文に存在しないため、事実を追加して作らないよう注意した）。
- **カード化しなかった細部**: 「match() を古い Python バージョンとの互換性が必要なコードで使う際の注意」「`re.VERBOSE` の三重クォートでのフォーマット例・比較用の1行コード」は省かれているが、主要論点の復習には寄与が小さく、プロンプトの「原文の全事実を網羅する必要はなく …削ってかまいません」の範囲内と判断した。修正版でも追加していない。
- **CSV 構造**: 1行1ノート・1ノート1フィールド・RFC 4180 の二重引用符は下書き・修正版ともに正しい。内部に二重引用符を含むノートはなく、コード断片はすべてバッククォートで囲まれている。
- **ヒント**: いずれの空欄も文脈から答えの種類が明らかであり、ヒント不要と判断した（プロンプト「ヒント」の「文脈から明らかな場合は省略してかまいません」）。
- **文体・単独読解性**: 全ノートがです・ます調で統一され、「前述の」「このドキュメントでは」等の依存表現は見られない。Note 7→Note 8（修正版）と並べ替えていないため、まとめノート追加に伴うノート番号のずれ（下書き Note 8〜10 が修正版 Note 9〜11 に相当）が生じたが、内容の変更はしていない。
